Fiecare proiect este o colaborare — o idee care capătă formă vizuală. Iată o selecție din lucrările noastre.

Cum adaugi proiecte noi
1. Copiază screenshot-ul proiectului în folderul poze/ din site.
2. Deschide fișierul projects.json cu Notepad.
3. Adaugă un rând nou după modelul de mai jos și salvează:

— Pagină de prezentare: { "titlu": "Numele site-ului", "categorie": "prezentare", "poza": "screenshot.jpg", "descriere": "Scurtă descriere.", "url": "https://adresa-site.ro" }

— Landing page: { "titlu": "Numele proiectului", "categorie": "landing", "poza": "screenshot.jpg", "descriere": "Scurtă descriere.", "url": "https://adresa-site.ro" }

— Magazin online: { "titlu": "Numele magazinului", "categorie": "magazine", "poza": "screenshot.jpg", "descriere": "Scurtă descriere.", "url": "https://adresa-site.ro" }

Categoria poate fi: prezentare, landing sau magazine.
